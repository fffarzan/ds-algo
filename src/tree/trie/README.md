# Trie (Prefix Tree)

- It is used for strings, not other types of values.
- It's a type of DFS.
- We can create a string as a tree:

```js
const apple = "apple";

//    ''
//   /
//  a
//    \\
//     p
//      \\
//       p
//      /
//     l
//    /
//   e
```

## Time Complexity

- Insert word: O(1)
- Search word: O(1)
- Search prefix: O(1)
