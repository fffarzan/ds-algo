# Problem

You are given an array of length `n` which was originally sorted in ascending order. It has now been rotated between 1 and `n` times.

Assuming all elements in the rotated sorted array `nums` element of this array `nums` are unique, return the minimum element of this array.

### Rotating

Rotating the array 4 times moves the last four elements of the array to the beginning. For example `nums = [1,2,3,4,5,6]` becomes:

- `[3,4,5,6,1,2]` if it was rotated 4 times
- `[1,2,3,4,5,6]` if it was rotated 6 times

# Complexity

- Time: O(logn)
